# Cone Vision

スマートフォンのカメラや写真から交通コーンを検出し、選択したコーンの5点特徴点・距離を表示する **実験用PWA** です。推論は端末内で動作します。

## 写真のEXIFから画角を自動設定

写真を読み込むと、35mm判換算焦点距離などのEXIFから水平画角を推定し、PnPのカメラ内部パラメータへ概算値を反映します。スキャン前に値を確認・手動変更できます。カメラ校正JSONがある場合は校正値を優先します。詳しくは [EXIF画角推定の説明](docs/EXIF_FOV.md)。

## 操作

1. 「カメラで撮影する」または「ギャラリーから画像を選択」
2. 写真を確認して「スキャンする」
3. 検出されたコーンを画像上または一覧から選択
4. 距離、奥行き、検出スコアを確認

見落としたコーンは、結果画面の「範囲を選んで再検出」で周囲に少し余白を含めてドラッグし、指を離すと再検出できます。全体スキャンが0件でも使えます。特徴点と距離は元写真の座標・画角で計算します。

### カラー点群・LAS

誤検出は写真の枠または一覧で選び、「このコーンを削除」で取り除けます。結果JSON・3Dの奥行き補正には残ったコーンを使います。「削除を取り消す」で元に戻せます。範囲再検出では削除を維持し、全体を再スキャンすると検出結果を作り直します。

測距できたコーンが2個以上になると「3Dで見る」が表示されます。設定または3D画面から、以下の深度モデルを選べます。選んだモデルは初回使用時に取得し、「保存データを削除」で消去できます。

| 深度モデル | ダウンロード容量 | 重みのライセンス |
|---|---:|---|
| Depth Anything V2 Small Q4（初期値） | 27.4 MB | Apache-2.0 |
| Depth Anything V2 Base Q4 | 102.3 MB | CC BY-NC 4.0（非商用） |
| Depth Anything V3 Small INT8 | 28.9 MB | Apache-2.0 |
| Depth Anything V3 Base FP16 | 207.2 MB | Apache-2.0 |

「距離画像」を選ぶと、コーンで補正したカメラ前方の奥行きを写真と同じ向きで表示します。近くは黄色、遠くは青色で、凡例の単位はmです。隣の「カラー画像」では深度推定に使った写真を同じ画角・解像度で見比べられます。各タブの切り替えに再推論は不要です。

コーンの軸の中点を写真に投影し、その周囲3×3画素の深度中央値を使います。各コーンについてPnP奥行きとモデル奥行きの比を計算し、全有効コーンの倍率中央値で画像全体を補正します。V2の出力は逆奥行きなので、逆数にしてから比を求めます。描画と書き出しには同じRGB点群を使い、奥行きの上限は40 mと最遠の基準コーンの奥行きの3倍の大きい方です。

ドラッグで回転、ピンチまたはホイールで拡大縮小できます。PCではマウスの中ボタン（ホイール）を押したままドラッグすると、グリッド面に沿って左右・前後に移動できます。「視点を戻す」で最初の位置に戻ります。1 mグリッドは測距できたコーンの底面位置・向きから推定した面に表示し、5 mごとに線を強調します。「LASを保存」はカメラを原点に、X右・Y前・Z上のローカル座標（m）とRGBをLAS 1.2形式で書き出します。グリッドは表示専用です。

GitHub Pagesにデプロイすると `https://kasys1422.github.io/cone-vision/` で利用できます。

## ローカル実行

```bash
python -m http.server 8877
```

`http://localhost:8877/` を開きます。カメラは原則HTTPSまたはlocalhostが必要です。初回はONNX Runtime WebをCDNから読み込むためインターネット接続が必要です。

## 単体の大型検出器

標準の検出器は **FCOS ResNet-50（512px）** です。固定実写テストでは正検出55/63個・誤検出3枠でした。PCの単一スレッドWASMで処理時間の中央値は2.14秒です。最初のスキャンで検出器と特徴点モデル（計約63 MiB）を取得します。ダウンロード中は転送量、推論中は「画像を推論中」と表示します。ホームの「保存データを削除」で端末に保存した全モデルを削除できます。次回スキャン時に必要なモデルを再取得します。[学習条件と比較結果](models/fcos_r50/MODEL_CARD.md)

設定の **FCOS ResNet-18（中間）** は512pxの検出器（26.3 MiB）で、標準モデルと同じ特徴点モデルを使います。[学習条件としきい値の比較](docs/FCOS_R18_THRESHOLD_C.md)

## V12 のモデル

- 設定から軽量なV10 YOLOX-Nano（256px）やSSDLite320-MobileNetV3-Large（320px）も選べます。設定の「SSDLite」は実写＋合成画像で学習したモデルです。
- 特徴点モデルは元の写真から192×192のROIを取得し、先端と台座4隅を推定します。各点の周囲を局所CNNで補正します。
- 保存済みのONNXは次回のスキャンで再利用します。Web設定の検出しきい値の初期値は0.65です。
- 距離を求めるときはOpenCV.jsのPnPを使います。EXIFや手動画角を使った値は概算です。実測距離と比較した精度は未評価です。

コーン検出・特徴点推定・深度推定は、初期設定でWebGPUを優先します。WebGPUの初期化や推論に失敗すると、該当モデルをWASMで再試行します。設定で「WebGPUを優先」をオフにすると最初からWASMを使います。

詳しい学習・評価の結果は [モデルカード](models/tracon_v12/MODEL_CARD.md) にあります。
