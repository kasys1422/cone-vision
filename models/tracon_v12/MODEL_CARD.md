# Cone Vision V12

Web標準はV10のYOLOX-Nanoと、今回再学習した192px特徴点モデルです。下表のV12列は、新しい検出器として検証分割で選んだSSDLite320-MobileNetV3-Large（実写専用）と同じ特徴点モデルの組み合わせです。個別のONNXの仕様は同じディレクトリのinterface.jsonに記載しています。

| 同一テストでの指標 | V10検出器＋V11特徴点 | 実写SSDLite＋V12特徴点 |
|---|---:|---:|
| 実写検出 mAP@50 | 68.05% | 72.27% |
| 実写検出 mAP@50:95 | 37.75% | 44.69% |
| 正検出 / 誤検出 / 見落とし | 42 / 9 / 21 | 38 / 8 / 25 |
| 実写の空画像21枚の誤検出枠 | 0 | 7 |
| 元画像の高さ96px未満で検出できた数 | 0/7 | 0/7 |
| 正解枠での特徴点平均誤差 | 11.57px | 11.21px |
| 検出から通した可視点 PCK@0.05 | 35/63 | 24/63 |
| 合成で測距判定通過かつ距離誤差10%未満 | 152/285 | 90/285 |

実写検出は43枚・63対象。実写特徴点は7撮影群・15対象・63可視点。PCK@0.05は点誤差が正解ROIの一辺の5%未満となった割合で、上表の検出からの評価では未検出も失敗に含めます。合成の測距は200枚・285対象で、既知のカメラ行列とコーン形状を使用しました。実写のメートル単位の誤差は未評価です。

検出スコアは0.50、正解との対応とNMSのIoUは0.50です。AP曲線の下限スコアは0.01としました。ONNXのCPU実行で既存の重みを再評価した数値を掲載しています。過去のバージョンで使ったテスト分割を引き継ぎ、最終モデルの選択には検証分割を使用しました。

## Webアプリの既定値

上表のV12列は実写専用SSDLiteと局所補正版の組です。実写mAPは向上しましたが、同じしきい値で測距まで通した成績を踏まえ、Webアプリの標準には **V10 YOLOX-Nano＋V12特徴点** を用います。この組み合わせの実写PCKは37/63点、合成測距成功は151/285対象です。「コーンの寸法・カメラ設定」で実写専用または混合学習版のSSDLiteに切り替えられます。
