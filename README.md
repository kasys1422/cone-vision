# Cone Vision

スマートフォンのカメラや写真から交通コーンを検出し、選択したコーンの5点特徴点・距離を表示する **実験用PWA** です。推論は端末内で動作します。

## 写真のEXIFから画角を自動設定

写真を読み込むと、35mm判換算焦点距離などのEXIFから水平画角を推定し、PnPのカメラ内部パラメータへ概算値を反映します。スキャン前に値を確認・手動変更できます。カメラ校正JSONがある場合は校正値を優先します。詳しくは [EXIF画角推定の説明](docs/EXIF_FOV.md)。

## 操作

1. 「カメラで撮影する」または「ギャラリーから画像を選択」
2. 写真を確認して「スキャンする」
3. 検出されたコーンを画像上または一覧から選択
4. 距離、奥行き、検出スコアを確認

GitHub Pagesにデプロイすると `https://kasys1422.github.io/cone-vision/` で利用できます。

## ローカル実行

```bash
python -m http.server 8877
```

`http://localhost:8877/` を開きます。カメラは原則HTTPSまたはlocalhostが必要です。初回はONNX Runtime WebをCDNから読み込むためインターネット接続が必要です。

## V12 のモデル

- 標準の検出器はV10 YOLOX-Nano（256px）です。設定から、今回再学習したSSDLite320-MobileNetV3-Large（320px）に切り替えられます。実写専用と実写＋合成の2種類を収録しています。
- 特徴点モデルは元の写真から192×192のROIを取得し、先端と台座4隅を推定します。各点の周囲を局所CNNで補正します。
- 起動時に `models/tracon_v12/` の2つのONNXを読み込みます。検出スコアの既定値は0.50です。
- 距離を求めるときはOpenCV.jsのPnPを使います。EXIFや手動画角を使った値は概算です。実測距離と比較した精度は未評価です。

詳しい学習・評価の結果は [モデルカード](models/tracon_v12/MODEL_CARD.md) にあります。スマートフォン実機とWebGPUでの検証は別途必要です。
