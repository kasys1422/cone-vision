# 写真のEXIFからの画角自動推定

**Cone Vision実験版（v7）の機能**。画像をギャラリーから読み込むと、元ファイルのEXIFを読み取り、水平画角（HFOV）を推定します。カメラ撮影モードでは、`getUserMedia()` のフレームにEXIFが付かないため自動計算は行わず手動設定を使用します。

## 対応するEXIF

- JPEG APP1 Exif、PNG eXIf、WebP EXIF（ファイル先頭2MiB以内）
- `FocalLengthIn35mmFilm` (0xA405)、画像サイズ、Orientation
- 35mm判換算焦点距離がない場合は、`FocalLength`、`FocalPlaneXResolution`、`FocalPlaneResolutionUnit`、画像ピクセル数がすべてそろう場合に限り代替推定
- `FocalLength` しかない場合は推定しない（センサー寸法が不明なため）
- 既知のデジタルズーム・EXIFと画像の縦横比の不一致がある場合、自動適用を中止
- HEIC/HEIFに対するEXIF独自解析は未対応。ブラウザが画像自体を表示できる場合でも、画角は手動入力となることがある

## 計算

35mm判換算焦点距離を f35、画面に展開した画像サイズを W×H とすると、

```
f_px = f35 * hypot(W, H) / hypot(36, 24)
HFOV = 2 * atan(W / (2 * f_px))
K = [[f_px, 0, W/2], [0, f_px, H/2], [0, 0, 1]]
```

内部パラメータ K はピンホール近似であり、正確な校正値ではありません。EXIFの倍率定義、画角補正・レンズ歪み、動画からのスクリーンショット、パノラマ合成、アスペクト比を維持したトリミングで誤差が生じます。特に超広角・望遠・画像補正済み写真では注意してください。

## 動作

1. ギャラリーから写真を選択すると自動推定。撮影した元ファイルのメタデータは端末内で読み取り、GPS・シリアル等は収集しません。
2. スキャン前の確認画面で画角と自動・手動の区分を表示します。数値を編集すると手動設定に切り替わります。
3. ホームの設定画面から「EXIFの画角に戻す」で再適用できます。
4. カメラ校正JSON（K）が入力されている場合は**その値を優先**します。画像と校正サイズが矛盾する場合は処理を止めます。
5. EXIF推定の測距は**参考値（概算）**であり、精度が保証されたメートル単位の測距ではありません。

## テスト

```
node --test tests/exif_fov.test.mjs
```

JPEGのエンディアン、縦位置写真、ズーム、クロップ、35mm換算値欠落、焦点面解像度代替、PNG/WebP、欠損メタデータを確認します。実ブラウザでのPWA操作と実際のスマートフォン写真・校正付き測距については別途確認が必要です。
